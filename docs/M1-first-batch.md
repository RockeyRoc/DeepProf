## 本批交付

- 固定 A/B 会话配置：课程、分组、模型、检索和采样配置随会话保存。A 走普通苏格拉底提示，B 走教学图；两组都不读取跨题学情状态。
- 接通 Gateway、CLI、RuntimePort、能力绑定和只读回放。命令使用 `command_id` 幂等，同一会话串行执行；成功、失败、取消和进程中断都有终态或恢复记录。
- 教学决策记录 `policy_version`、规则原因和可定位证据引用。Hint 上限为三级；证据不足时停止无依据讲解；未获可靠判分时不生成作答事实。
- 接通 `quiz.generate` 与 `quiz.answer`。出题响应不返回标准答案；作答关联当前题目和会话。仅来源、评分规则均已复核的确定性题目自动判分并写入 Attempt；命令重放不会重复记分。开放题保留人工评分，禁用自动评分。
- Ask 输出先在服务端缓冲并做规则检查；规则检查失败时使用安全的确定性追问。回放及普通事件流只暴露允许字段，隐藏学生正文、教材正文、答案和 Provider 敏感错误内容。
- 提供开发者测试目录、安装启动器、`deepprof login`、健康探测、A/B 验收、反馈和报告命令。登录密钥通过本机 DPAPI 存储，不写入仓库或会话事件。
- 活动产品路径以 CLI + 本机 Gateway/API + 教学图为核心；桌面端、桌宠、语音、插件运行时、爬虫、PaperReader 和 Pi 集成退出本阶段主路径。旧存储兼容模块保留，未接入教学 Runtime。
