## 一、交付范围与责任边界

本模块严格遵守 D-7（§4.4 / §7.1）的分工，**图只做 WHAT，Runtime 只做 HOW**：

| 归属 | 内容 | 落点 |
| --- | --- | --- |
| 教学策略（图侧） | 阈值、分支条件、文案模板、提示词模板、绑定表 | `graph/education/policies/` · `graph/education/bindings.py` |
| 声明式决策 | `PedagogicalDecision`（action / concept / level / params / reason） | `graph/education/contracts.py` |
| 执行能力（Runtime 侧） | 六个通用原语 `render_template` / `invoke_skill` / `retrieve_evidence` / `generate_grounded` / `read_memory` / `write_memory` | `runtime/capabilities.py`（非本模块，仅按绑定表引用） |
| 教材证据 | 只以可定位引用（document_id / chunk_id / page）进入图状态 | 经绑定表向 RAG 组消费 |

**本模块不 import 任何 Provider / Storage / ToolRegistry / 模型 SDK**；节点只依赖窄面 `RuntimePort`（`execute` / `emit`）。这两条由 §7 的架构守卫测试强制执行（见 §5）。

## 四、教学样例：输入 → 预期 → 实际输出

以下均为本机实跑输出（`FakeRuntime` + 脚本化模型回复 `（模型回复）先看你的思路。`），非文档推测。

| # | 输入样例 | 预期输出（action） | 实际输出 | 引用数 |
| --- | --- | --- | --- | --- |
| 1 | 「请讲讲什么是梯度下降」（有证据） | teach（贴合教材） | `teach` / `explaining` | 1 |
| 2 | 「我没学过前面的导数，这块还能听吗」 | teach（**讲前置概念**，不追问） | `teach` / `explaining` | 1 |
| 3 | 「我觉得可以先求偏导」 | ask（苏格拉底追问，不泄露答案） | `ask` / `curious` | 0 |
| 4 | 「还是算不出来」+ 连续答错 1 次 + hint_level=1 | hint（升级到第 2 级） | `hint` / `encouraging`，级别 2 | 0 |
| 5 | 「我认为是沿正梯度方向走」+ 连续答错 3 次 | correct（指冲突、给对比例，并清零错误计数） | `correct` / `patient` | 1 |
| 6 | 测验-评价作答（题库未接入） | test（判对帧 + 声明题库未接入） | `test` / `attentive` | 0 |
| 7 | 「请讲讲什么是梯度下降」（无证据） | teach（证据不足固定表述，**零引用**） | `teach` / `explaining` | 0 |
| 8 | 「我不想学了」（学生停止） | end（收束语，不进入教学动作） | `end` / `warm` | 0 |

场景 2 的"起讲点前移"通过模型提示词验证（不是只看 action）：

```
prompt_has_prior_gap_note = True
```

即送入模型的用户提示词含 `PRIOR_GAP_TEACH_NOTE`（"先补齐最基础的一步……不要用追问要求他自行推理"），
且**不含** `PRIOR_OK_TEACH_NOTE`（"可以精简基础步骤"）。先验判定只认**学生自述**（关键词意图），
不从"学情记忆为空"反推没掌握——那等于给学生贴永久标签（§13.1）。

### 场景 7 实际输出（无证据不编造引用）

```
（证据不足）教材检索没有返回可定位的原文片段，因此本轮讲解不给出任何来源与引用。
下面只是通用的思考路径，不作为教材结论：先回到定义与前置概念，……
```

### 场景 8 实际输出（学生停止即退出）

```
好，本轮先到这里。我已经把本轮的学习情况写入可撤回的学情记忆，
你随时可以让我更正或删除它。下次我们接着这个知识点继续。
```

## 五、作答事实（Attempt）交接：教育组 → 数据组（§16.3 / §18.2）

**责任分工**：Attempt 的**契约**由数据组定义（`models/learner/attempt.py`），
**产出与发送**由教育组在 Test / Correct 节点完成，随 `pedagogy.attempt` 事件落盘供数据组消费（BKT / IRT 输入）。

产出闸门由 `policies.attempt_gate` 唯一给出，三条必要条件缺一不可：

| 条件 | 不满足时的行为 | 依据 |
| --- | --- | --- |
| 归属明确（`learner_id` 非空） | 不产出，避免跨学习者污染画像 | §13.2 |
| 判分可靠（`correct` 为显式 bool） | 不产出，不得把"判不了"当成答错 | §13.1 |
| 题目可追踪（`item_id` 非空） | 不产出，不编造无法与题库对齐的 id | §18.2 |

跳过时**必须**在决策事件里写明 `attempt_skip_reason`，静默跳过会被误判为链路故障。

### 实测：当前生产真实状态（题库未接入）

```
[6 测验-评价作答(题库未接入)] action=test  attempt_events=0
    skip_reason=缺少可追踪 item_id（课程题库未接入）：不产出 Attempt，不编造无法与题库对齐的 id（§18.2）
```

### 实测：题目可追踪时产出成功路径

```
[9 有 item_id] action=test  attempt_events=1  skip_reason=
```

产出的 payload 能通过数据组契约 `Attempt` 校验（`model_validate`），
且失败路径逐条可验：缺 `item_id` / 判分为 `None` / 缺 `learner_id` 三例均不产出并给出对应原因（`test_education_attempt.py`）。

## 六、失败案例与待补依赖（非阻塞）

以下四项**不影响本轮判定**，但必须在下一轮由对应责任人补齐；本轮一律以"显式不产出/显式说明"处理，不做隐式兜底。

| # | 现象 | 本轮处理（诚实状态） | 待补依赖 / 责任 |
| --- | --- | --- | --- |
| 1 | **课程题库未接入** | `QUIZ_NOT_CONNECTED_NOTE` 明示；`item_id` 为空 → Attempt 走 skip 分支并写明原因 | 题库与来源映射 → 许阳毅 |
| 2 | **自动判分未接入** | 判分三态（对/错/判不了）；`last_answer_correct` 缺失即 `unknown`，不更新 `wrong_streak`、不写学情、不产出 Attempt | 判分链路 → 欧阳文凯 |
| 3 | **学情模型未接入** | `diagnose` 返回 `not_implemented`，图侧退化为规则化观察（带 source / confidence / expires_at / revocable / model_version） | BKT / IRT → 欧阳文凯（§18.1） |
| 4 | **苏格拉底 Skill 未注入时** | Ask 走绑定表声明的策略兜底模板（实测场景 3），避免直接泄露答案 | `skills/socratic` 接入 → 教育组 |

**第 1 项的技术根因（须在下一轮解决）**：当前 `state["item_id"]` **没有真实写入方**——
Quiz Skill 返回的 `item.item_id` 为空串，Runtime 的 `invoke_skill.passthrough` 只支持顶层键（不支持点路径），
而 `SessionRequest` 字段已在 §18.2 冻结、不能新增 `item_id`。
因此 **Attempt 成功路径目前只能由测试注入 `item_id` 触达**（见 §5 场景 9），
生产链路上稳定走 skip 分支。修复方向（三选一，需与数据组/接口归口确认）：
① 题库接入后由 Quiz Skill 返回可追踪 `item_id` 并经 `passthrough` 白名单带回；
② Quiz 结果改为顶层字段承载 `item_id`，避免点路径；
③ 由 Session 元数据在轮间传递题目标识（不改冻结字段）。

三条架构守卫（`tests/test_architecture_boundaries.py`）：

1. `runtime/` 不得反向 import `graph/` / `skills/` / `pet/`；
2. `runtime/` 字符串常量不得含教学动作词（`hint` / `teach` / `correct` / `reflect` / `socratic`）；
   `pedagogy.*` 事件类型不在禁止之列，故 `pedagogy.attempt` 合法；
3. `graph/` 只能通过窄面 `execute` / `emit` 访问 Runtime（禁止 `.invoke_skill` / `.generate` / `.read_memory` / `.write_memory` 属性访问）。
