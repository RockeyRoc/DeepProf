# 极限与连续

极限描述变量无限接近某个目标时函数值的稳定趋势。计算极限时，应先判断代入是否有定义，再根据因式分解、有理化或等价无穷小化简。函数在一点连续，需要函数值存在、极限存在，并且两者相等。连续函数在闭区间上一定有最大值和最小值。

# 导数与切线

函数在点 x0 的导数是差商在增量趋于零时的极限。导数表示函数图像在该点切线的斜率，也表示瞬时变化率。和、积、商的求导法则把复杂函数拆成基本函数；复合函数使用链式法则。若函数在区间内部取得极值且可导，极值点通常满足导数为零。

# 微分与近似

微分是函数增量的线性主部。对可微函数，dy=f'(x)dx 可以用于局部近似和误差估计。线性化把函数在基准点附近替换为切线，二阶导数则帮助判断局部凸性以及极值类型。

# 积分与原函数

不定积分表示原函数的全体，计算时要在结果后加积分常数。定积分可以理解为带符号面积，也可以由黎曼和的极限定义。微积分基本定理把定积分和原函数连接起来：对连续函数，积分函数的导数等于被积函数。

# 积分技巧

换元积分通过替换变量简化复合表达式，使用时必须同步替换微分。分部积分来自乘积求导公式，常用于多项式与指数、对数或三角函数的乘积。广义积分需要检查无穷区间或无界函数附近的收敛性。

# 向量与矩阵

向量的线性组合由标量乘法和向量加法构成。向量组线性无关意味着只有全零系数才能得到零向量。矩阵乘法表示线性变换的复合，乘法通常不满足交换律。可逆矩阵存在逆矩阵，且行列式不为零是方阵可逆的等价条件。

# 概率与统计

概率的加法公式处理并集事件，乘法公式处理联合事件。条件概率 P(A|B) 只在 P(B)>0 时定义。独立性意味着联合概率等于边缘概率之积，但互斥事件通常并不独立。随机变量的期望是长期平均，方差衡量偏离期望的波动程度。

# 梯度与优化

梯度由各个偏导数组成，指向函数增长最快的方向。梯度下降沿负梯度更新参数，以便减小损失函数。学习率过大可能振荡或发散，过小则收敛缓慢。凸函数的局部最小点也是全局最小点，这是优化中很重要的可解释性质。
