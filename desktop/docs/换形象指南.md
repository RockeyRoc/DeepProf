# 桌宠换形象指南

> **什么时候看这份**：要把桌宠的角色换成另一个形象。
> **结论先给**：换形象 = **重出图 + 跑 3 条命令 + 替换文件**，**代码一行都不用改**。
> 写于 2026-09-19

---

## 〇、换形象 = 替换文件，不是改代码

素材是按**目录 + 固定文件名**组织的，文件里**不含任何形象信息**：

```
desktop/src/renderer/src/assets/pet/
  expressions/   idle.png  think.png  teach.png  ask.png  hint.png
                 correct.png  quiz.png  happy.png  sad.png      ← 9 张表情
  frames/walk/   walk_0.png walk_1.png walk_2.png walk_3.png    ← 走路 4 帧
  frames/blink/  blink_0.png blink_1.png                        ← 眨眼，叠在待机上
  frames/talk/   talk_0.png  talk_1.png                         ← 说话嘴部开合
  rig/           body.png  leg_left.png  leg_right.png + rig.json  ← 分层模式用
```

**新形象按同样的文件名放进去，桌宠就跑新形象了。**
（`petAnimations.js` 里的 `import` 路径、`geometry.json` 都由脚本产出，不用手改。）

---

## 一、⚠️ 四个硬约束（踩了要返工）

| # | 约束 | 踩了会怎样 |
| --- | --- | --- |
| 1 | **所有图必须同画布尺寸**（现在 1536×1536）、脚底同一基线、头心对齐 | 切动作时角色**忽大忽小、左右跳** |
| 2 | **`geometry.json` 必须与 PNG 匹配** | ⚠️ **这是本项目最坑的 bug**：曾经 PNG 是 768 而 geometry 写 1536 → 缩放按 1536 算、贴图只有 768 → **角色恒为一半大**，不报错、不崩溃，查了一晚上 |
| 3 | **走路帧必须是侧视朝右** | 正面走路时腿往屏幕里外摆，横移时看不出在迈步 → **像贴纸在滑**（4 帧也救不回来）。朝左不用另出图，播放器有水平翻转 |
| 4 | 眨眼 / 说话帧要和 idle **身体轮廓一致** | 不一致 → **说话时"变胖"**、眨眼时脸鼓一下（踩过；修法是 `对帧.py --横缩` 横向压缩） |

**约束 1、2、4 流水线会自动处理，不用手工对齐。约束 3 只能靠出图时把住。**

---

## 二、完整流程

### 第 1 步：出图（**主要成本在这一步**）

要出 **17 张**，全部**传同一张参考图**（现在的角色立绘）保持一致性：

| 用途 | 张数 | 视角 | 说明 |
| --- | --- | --- | --- |
| 表情立绘 | 9 | 正面 | `idle / think / teach / ask / hint / correct / quiz / happy / sad` |
| 走路 | 4 | **侧视朝右** | **一次生成"四格连续动作图"再裁开**，比例天然对齐（见下） |
| 眨眼 | 2 | 正面 | 睁眼 / 闭眼。**睁眼那张直接用 idle**，不用单独出 |
| 说话 | 2 | 正面 | 闭口 / 张口。**闭口那张直接用 idle** |

**Prompt 在哪**：`DeepProf_生图Prompt包.md`（逐张 Prompt 与参数）。

> **走路的推荐做法**：一次生成"四格连续动作分解图"，再裁开。
> AI 逐张生成时四张的比例画风会飘；同一张画布内生成则天然对齐。
> 裁图不用手切：把四格图丢进 `动作帧/原始/walk/`，跑 `python 裁四格.py walk`。

### 第 2 步：跑流水线

素材放这里（**文件名必须按规范**）：

```
../tools/素材流水线/动作帧/原始/
  表情/   idle.png think.png teach.png …
  walk/   walk_0.png walk_1.png walk_2.png walk_3.png
  blink/  blink_1.png        ← 睁眼那张直接复制 idle.png 当 blink_0
  talk/   talk_1.png         ← 闭口那张直接复制 idle.png 当 talk_0
```

```bat
cd _素材工作区

:: ① 抹平出图端的画幅差异（**最容易漏的一步，见下**）
python 对帧.py blink
python 对帧.py talk

:: ② 统一画布 / 脚底对齐 / 头心对齐，并生成 geometry.json
python 归一化帧.py 表情 --模式 表情
python 归一化帧.py blink --模式 逐帧
python 归一化帧.py talk  --模式 逐帧
python 归一化帧.py walk  --模式 逐帧

:: ③ 出预览，**必须看**
python 预览.py walk
```

不想敲命令就**双击 `做动作帧.bat`**（不填参数 = 处理全部动作）。

> ⚠️ **为什么第 ① 步不能省**：即梦出图时**画布和角色会一起缩放**。
> 实测过：`idle` 是 1728×2304（角色高 2190），眨眼帧却是 2048×2048（角色高 1970）——
> **角色相对小了 24%**。而 `归一化帧.py` 只统一高度、**不统一宽度**，
> 于是眨眼时脸会明显缩一下。`对帧.py` 就是修这个的。
>
> 如果新素材**宽度**也对不上（AI 把角色整体画宽了），用：
> ```bat
> python 对帧.py talk --横缩_ 1:0.95     :: 只压横向、不改高度
> ```

### 第 3 步：看预览、确认、接入

**接进桌宠之前必须看** `动作帧/预览/<动作>_拼版.png`：

- [ ] 所有帧的脚底**都踩在红线**上
- [ ] 所有帧的头**都落在蓝虚线**上
- [ ] 帧与帧之间**没有忽然变大变小**
- [ ] 棋盘格上**没有白边/灰边**残留
- [ ] 动图看起来**像在走路**，不是抽搐

满意了加 `--接入` 直接拷进桌宠素材目录：

```bat
python 归一化帧.py walk --接入
```

### 第 4 步：分层模式（可选）

分层走路那套要单独拆（它只用**一张** idle 图，不需要额外出图）：

```bat
python 拆腿.py --裁到角色 --接入
python 预览rig.py            :: 跑两条硬校验
```

> ⚠️ `--裁到角色` **别省**。`RigPet` 是按**整张画布**算缩放的，
> 而新表情立绘四周有大片透明边距（角色只占 41%宽）→ 会触发**宽度约束**，
> 角色显示高度从 292px 掉到 172px（**小了 41%**）。裁掉透明边距就恢复。
>
> `预览rig.py` 会跑两条硬校验：**零角度必须逐像素还原原图**、**延长区必须被身体完全盖住**。
> 有一条不过就别接进桌宠。

## 三、什么时候**需要**改代码

换形象本身不用改代码。但下面这些情况要：

| 情况 | 改哪 |
| --- | --- |
| 想加/减表情（比如不要 `sad`） | `petAnimations.js` 的 `ANIMATIONS` + `NODE_TO_ANIMATION` |
| 想换画布尺寸（比如 2048） | `归一化帧.py` 的 `_规格.json` —— ⚠️ **全局规格，改了所有动作都要重跑** |
| 想改走路帧率 / 眨眼间隔 | `petAnimations.js` 的 `walk.fps` / `blink.holds` |
| 角色显示大小不合适 | `FramePet.jsx` 的 `IDEAL_H`（230）/ `RigPet.jsx` 的（292）<br>⚠️ **同时**要改 `styles.css` 里气泡的 `bottom`（248 / 310），否则气泡会挡脸 |

---

## 四、别踩这些坑（实测踩过）

1. **`_规格.json` 是全局的** —— 所有动作共用一套（画布 1536 / 角色高 1200 / 脚底线 92%）。
   一旦开始出正式素材就**别改它**；要改就全部重跑归一化。
2. **归一化只统一高度，不统一宽度** —— 宽度差要靠 `对帧.py --横缩` 补。
3. **改素材后一定要看预览** —— 脚本会喊警告（帧间高度差 >10%、头部水平偏移 >4%），
   **别忽略**，那意味着播起来会耸动或左右晃。
4. **别手改 `assets/pet/` 下的 PNG** —— 它们是脚本产物，改了就和 `geometry.json` 对不上。
5. **素材换了要补记录** —— `ASSETS_LICENSE.md` §三 要求「任何一张新素材进入 `assets/`，
   都要在生成记录里加一行」。这是授权合规用的。

## 五、换完自检

```bat
cd desktop
npm run dev
```

- [ ] 待机姿势正常、脚底贴窗口底边
- [ ] 右键菜单逐个切教学节点按钮，**9 个表情都对得上**
- [ ] 「随便走走」——**腿在迈**，不是整个人平移
- [ ] 待机一会儿——**偶尔眨眼**（3~7 秒随机一次）
- [ ] 发一句话——回复流式输出时**嘴巴开合**
- [ ] 切「换成分层走路」——角色大小和逐帧模式**差不多**，走动时不露缝

> ⚠️ 换了素材后如果发现**角色大小不对**，**先查"PNG 和 geometry 是否对得上"**，
> 而不是去改缩放系数 —— 那条路历史上走错过一次（见 §一 约束 2）。
