# 遇到问题怎么办

| 现象 | 怎么办 |
| --- | --- |
| 生成出来**背景不是纯白**（有渐变、有花纹） | 加一句 `纯白背景，背景干净无杂物`，重新生成 |
| 角色**越生成越不像** | 检查参考图传了没。参考图没传是 90% 的原因 |
| 出现**女仆装 / 齐刘海 / 长裙** | 提示词里那三样禁不掉，多生成几次挑；实在不行把 `禁止：…` 那句提到最前面 |
| 画出来**腿被裙子盖住** | 加一句 `裙子长度在膝盖以上，大腿完整露出` |
| **一张都不满意** | 别硬用。告诉我，我们一起调 prompt |

<summary>为什么 prompt 里要写"禁止女仆装"（点开）</summary>

我们要避开的那个参考角色，最标志性的特征就是**女仆装 + 齐刘海长直发**。
不写进 prompt，AI 有相当概率自己往那个方向画 —— 那就撞车了，授权上有风险。

`长裙拖地` 是因为会**盖住腿**，腿看不见就走不了路。

<summary>尺寸和技术要求（出图时不用管，后面归一化会处理）</summary>

- 表情立绘 ≥1024px，动作帧 ≥512px
- 同一批必须同画布、脚底对齐 —— **但出图时做不到也没关系**，归一化脚本会帮你对齐
- 唯一要保证的：**同一批的角色大小别差太多**（脚本只能对齐，修不了"这张画大了 20%"）
</details>

<details>
<summary>为什么先出表情、后出走路</summary>

表情立绘决定"这个角色像不像" —— 如果 9 张表情出来发现角色不对劲，
那走路帧也会跟着不对。**先花小成本验证角色，再投入做动画。**
</details>
