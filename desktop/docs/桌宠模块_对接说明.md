## 一、先把桌宠跑起来

```bat
cd desktop
npm install          :: 首次（约几分钟；国内可能要设 ELECTRON_MIRROR）
启动桌宠.bat          :: 或 npm run dev
```

不需要后端、不需要密钥、断网也能跑（**目前全部是 Mock**）。

**验证它活着**：右下角出现小人 → 右键 →「打开对话」→ 点「正常回复」，
应看到气泡逐字输出（一轮约 9~10 秒，237 个事件）。

> ⚠️ **单实例锁**：重复启动会静默退出。退出请用托盘第一项或 `Ctrl+Alt+Shift+X`。

## 三、★ 核心：把 Mock 换成真后端（4 处改动）

### 3.1 主进程：换掉 `MockRuntime`

**文件**：`desktop/src/main/index.js`

现状：`initRuntime()` 里 `runtime = new MockRuntime()`，事件由本机定时器产生。

要改成：调后端的 HTTP/SSE。后端端点（`api/routes/sessions.py`，前缀 `/sessions`）：

| 用途 | 端点 |
| --- | --- |
| 建会话 | `POST /sessions` |
| 发消息 | `POST /sessions/{id}/messages` |
| 教学轮次 | `POST /sessions/{id}/teaching-turn` |
| **事件回放** | `GET /sessions/{id}/events?from_sequence=N` |

**保持 `session:send` / `cancel` / `reconnect` 三个 handler 的签名不变**，
只改内部实现。渲染层与 preload 不用动。

> ⚠️ **后端目前没有 WebSocket**（只有 REST + SSE，见 `runtime/core/events.py` 的
> `open_event_stream` 注释）。所以要么用 SSE 收流式事件，要么轮询
> `/events?from_sequence=` —— **后者更省事，且天然支持断线续传**。

### 3.2 渲染层：补 4 个不认识的事件类型

**文件**：`desktop/src/renderer/src/App.jsx` → `handleEvent()` 的 `switch`

前端现在处理 15 种。后端 `runtime/core/events.py` 有 **29 种**，下面这些**前端不认识**：

| 后端事件 | 前端现状 | 要不要补 |
| --- | --- | --- |
| `session.ended` | ❌ 不认 | 建议：回待机 |
| `agent.started` | ❌ 不认 | 可选 |
| `agent.cancelled` | ✅ **已认**（2026-09-20 补） | — 前端 `App.jsx` 现在**两种写法都认**：`agent.cancelled` 与 `agent.failed{reason:'cancelled'}`。<br>⚠️ 补之前只认后者，而真后端取消时发的是**前者** → 状态**永久卡在 `streaming`**（不报错、不崩溃，只是取消按钮点了没用）。这行原先写的是「❌ 不认」，**已过期** |
| `tool.*`（5 种） | ❌ 不认 | 可选（想显示"正在查资料"时有用） |
| `plugin.*`（6 种） | ❌ 不认 | 本轮可忽略 |

> ⚠️ **不补不会报错，会静默忽略。** 这正是这个项目最怕的失败模式 ——
> 详见 `desktop/docs/已知限制.md` §9、§五。

### 3.3 渲染层：字段名差异（**最容易踩的一处**）

后端发教学结果用的是 **`pedagogy.result`** 事件，payload 形状：

```js
{
  action, response_text, emotion, citations, next_action,
  turn_count, hint_level, misconceptions, evidence_sufficient, strategy_note
}
```

⚠️ **注意 `response_text`，不是 `text`** —— 而 Mock 的 `model.completed` 用的是 `text`。

**这两条路前端都已经接住了**（`App.jsx` 里有 `pedagogy.result` 分支），
但如果你改后端改动了字段名，**记得同步前端**。

另外后端 payload 里有几个**前端还没有对应 UI** 的字段，接上后可以逐步用起来：
`citations`（引用来源）、`hint_level`（提示级别）、`misconceptions`（错因）、`strategy_note`（策略说明）。

### 3.4 断线重连：两边机制天然互补

**后端**：`GET /sessions/{id}/events?from_sequence=N` —— 只返回 `sequence > N` 的事件。

**前端**：`App.jsx` 里 `lastSeqRef`（`{session_id: 已处理的最大 sequence}`）
+ `seenIdsRef`（已见过的 `event_id`），**两张网都在**。

**接法**：重连时把前端记的 `lastSeqRef[session_id]` 作为 `from_sequence` 传过去，
就不重复渲染、也不丢事件。**这一条是本模块唯一"技术上依赖 sequence 字段"的验收项**，
后端别把 `sequence` 去掉。

## 七、别踩这些坑（都是实测踩过的）

1. **改了 `renderer/` 是热更新；改了 `main/` / `preload/` 必须重启。**
2. **`npm run start` 不会重新编译**，跑的是 `out/` 里的旧产物。改了源码没 `build` 就是"改了没生效"。
3. **打包时 `tools/tts/` 必须在 asar 外**（靠 `extraResources`）。主进程按
   `process.resourcesPath` 找它 —— 改成 `__dirname` 会让打包版语音静默失效。
4. **同一张精灵只能有一条写 `sprite.texture` 的路径** —— 两条会互相覆盖，表现为高频闪烁。
5. **给渲染组件加可选参数时，必须连 `null` 分支一起测** —— 只测正常路径等于没测。
   （踩过：`overlay` 为 null 时抛异常 → React 卸载整棵树 → **窗口变纯白**）
6. **素材帧新增后要同时量高度和宽度** —— 只对齐高度的话，AI 把角色画宽了就会"说话时变胖"。
   工具在 `../tools/素材流水线/对帧.py`。
