- **角色**：学院风双马尾鲸鱼少女（原创 OC；**名字待团队定**，注意不得含第三方商标）
- **生成方式**：**即梦 AI** 生成 → 团队用自研脚本做**确定性后期处理** → 透明 PNG
- **后期处理**：不是「修图」，是**可复现的归一化流水线**（见 §2.1）
- **存放位置**：`desktop/src/renderer/src/assets/pet/`

### 2.1 后期处理流水线（脚本在 `../tools/素材流水线/`）

| 脚本 | 输入 → 输出 | 做了什么 |
| --- | --- | --- |
| `动作帧/裁四格.py` | 四格连续动作图 → 4 张单帧 | 把**同一画布内**生成的走路四格切成 `walk_0`~`walk_3`。同一画布生成是刻意的 —— 比例与步态连续性是**天然对齐**的，逐张生成会飘 |
| `归一化帧.py` | 原始单帧 → 可播放帧 | ① 去白底 / 背景污染 ② **所有帧用同一个缩放系数**（逐帧缩到同高会抹掉走路时的自然起伏）③ 按**头部中心**水平对齐（按外接矩形对齐会左右抖）④ 脚底对齐到同一基线 ⑤ 产出角色外接框 `geometry.json` |
| `拆腿.py` | 一张平铺立绘 → 3 层 | 拆出 `body.png` / `leg_left.png` / `leg_right.png` + `rig.json`（髋点坐标、裙摆线）。切分逻辑与绕开的具体难点见脚本头注 |

> **归一化不是可选的**：AI 每次生成的角色大小、位置、脚底高度都不同，
> 直接播放会一帧一跳，比静态图还糟。
> 参考项目 `dsh-dfy` 因未做归一化、锚点与步态连续性全丢，整批帧作废重生成 ——
> 这是它 `SOURCE.md` 明确记录过的教训。我们把这一步固化成脚本，**处理过程可复现**。

### 4.2 为什么必须原创（有实据，不是偏好）

团队**曾评估过**网络上流行的「鲸鱼娘 / DeepSeek 娘」形象，结论是：**不能用，主动弃用。**

该形象的授权是 **CC BY-NC-SA 4.0**：

| 条款 | 含义 | 与本项目的冲突 |
| --- | --- | --- |
| **BY** | 必须署名 | 可满足 |
| **NC** | **禁止商业使用** | ❌ 计划书写了「**成果转化**」，属商业目的，直接违反 NC |
| **SA** | 衍生作品必须以**相同协议**共享（传染性） | ❌ 一旦采用，我们的衍生作品也必须 NC 授权，**转化路径直接堵死** |

- ❌ **软件著作权登记**要求**独创性**，使用他人 NC 素材登记**有被异议的风险**
- ❌ 「非营利就不算商用」是**误解** —— 成果转化、创业训练都是商业目的
- ✅ **结论**：保留「蓝鲸 + Q 版」的调性，但**换掉具体设计**，走原创路线，著作权 100% 归团队
