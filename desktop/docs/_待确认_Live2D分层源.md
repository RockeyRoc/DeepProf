## 1️⃣ 取消：三个问题 【要刘俊鹏回】

对账时发现**前端契约和后端实现在「取消」上对不上**。详细版见
`shared/contracts/_待确认_取消事件分歧.md`，这里只放结论。

**(a) 取消到底发哪个事件？**

| | 发什么 |
| --- | --- |
| Mock（前端自演） | `agent.failed({reason:'cancelled'})` |
| **真后端** | **`agent.cancelled({reason:'cancelled'})`** |

后端里 `AGENT_CANCELLED` 和 `AGENT_FAILED` 是**两个并列的独立类型**。
契约当初照 Mock 写，所以写了句「agent.failed 是取消的唯一表达方式」——**对真后端不成立**。

> **建议**：统一到 `agent.cancelled`，**改 Mock 而不是改后端**（后端有测试锁死了这个名字）。

**(b) `agent.cancelled` 不在「终结事件」名单里**

```python
_TERMINAL_TYPES = {AGENT_TURN_COMPLETED, AGENT_FAILED}   # ← 少了 AGENT_CANCELLED
```

目前靠订阅关闭兜住了、没暴雷，但名单漏了个终态。

**(c) 后端没有显式取消接口（这条最影响验收）**

`api/` 里翻遍了，**没有** `POST /sessions/{id}/cancel`。现在唯一能取消的办法是**客户端断开 SSE**。死结：

```
前端想取消 → 只能断开 SSE
          → 服务端才触发 CancelledError → 发 agent.cancelled
          → 但这条 SSE 已经断了，事件发不出去
          → 前端永远收不到「取消成功」的确认
```

而「流式文本与语音**可停止**」是 §16.4 的验收项，设计文档 §952 也把「退出可取消」列为里程碑门槛。

> **前端已经容错**（两个事件都接），所以**不影响现在演示** —— 是**接真后端时会踩**。

**要你回**：①②③ 三个 yes/no。

流式期间角色显示的是**当前教学表情**（嘴不动，但表情正常）。**本轮演示不受影响。**

**为什么不能直接放开**：

- `STATUS_TO_ANIMATION` 的优先级**高于**教学节点与情感标签（`petAnimations.js` 的 `resolveAnimation`）；
- 而 `status` 在**整轮对话期间一直停在 `streaming`** ——
  `pedagogy.node.entered`（`App.jsx`）只设节点、**不重置 status**，
  要等整轮 6 个节点走完的 `model.completed` 才回到 `idle`；
- 所以放开之后，**整个演示期间桌宠都停在说话帧**，
  9 个教学表情（含这轮新补的 `hint` / `correct` / `quiz`）**一个都看不到** ——
  「教学节点切表情」这条验收项**直接作废**。

> ⚠️ **这个理由不会因为素材到位而消失**，和"帧画的是旧角色"那个旧理由也不是一回事。

**两条路，选一条**：

| 方案 | 做法 | 代价 |
| --- | --- | --- |
| **A. 给 `status` 分级** | 让教学节点（以及情感标签）能**压过** `streaming`，`talk` 只在没节点时兜底 | 要改优先级链的语义，得重新验一遍所有状态的表现 |

**要你回**：走 A 还是 B？（**不接也完全可以** —— 不接不影响本轮演示和验收，只是北极星里「说话嘴部开合」这一条继续标未达成。）

### 一、为什么平面图不行

Live2D 不是"把一张图丢进去就会动"。它靠的是**把角色拆成许多可独立变形的部件**，
再在 Cubism Editor 里逐层绑骨骼、画网格、设参数。

```
平面 PNG：  整块。想动眼睛？只能换一张图（= 逐帧）
分层源：    眼睛、嘴、头发各自独立 → 参数一拉，眨眼/说话/头发飘全是连续动画
```

**关键区别**：分层之后，眨眼、说话、头发摆动**都不需要额外出图**，是骨骼算出来的。
这正是现在最卡的三样（眨眼/说话/走路）。

### 二、需要什么（具体清单）

按现在的 Q 版新角色，大致 **20~30 层**：

| 组 | 层 |
| --- | --- |
| 头发 | 后发 · 前发（刘海，压在脸上）· 呆毛 |
| 配饰 | 大蝴蝶结 · 鲸鱼发夹 · 耳饰（**单独拆**，才能跟着头摆动） |
| 脸 | 脸底 · 左/右眼白 · 左/右瞳孔 · 左/右上眼睑 · 左/右睫毛 · 左/右眉毛 |
| 嘴 | 闭嘴 · 微张 · 中张（3 个口型起） |
| 身体 | 脖子 · 躯干+裙 · 左臂 · 右臂 · 手 |
| 腿 | 左腿 · 右腿（**可复用现有的 `拆腿.py` 做法**） |
| 其他 | 腮红（可选） |

**格式要求**：
- **PSD 分层**（每层命名清楚、按上面的分组），或者直接给 **Cubism Editor 工程**
- **正面视角**，与现在的 6 张 Q 版**同一个人、同一套配色**
- 分层边界处**不要把像素切掉**（比如眼睛层要比眼眶略大一点，否则动起来露缝）
- 尺寸建议 ≥ 2048px，太小了动起来会糊

### 三、两条路在**美术分工**上差多少
