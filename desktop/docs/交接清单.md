## 一、给刘俊鹏（负责人 / Runtime）

### 1.1 前端消费什么

渲染进程**只有一个事件入口**：`preload` 暴露的 `runtime:event` 通道（§4.4「UI 不直连 Tool / Memory / Provider」的落地）。
所有事件都必须走这一条，**不要为图方便另开专用推送通道** —— 要加就加事件类型，登记进 `../../shared/contracts/events.json`。

当前已在消费的事件 **15 种**（`implemented: true`）：

```text
session.started      session.resumed      session.compacted
agent.turn.started   agent.turn.completed agent.failed
model.requested      model.stream.delta   model.completed   model.failed
memory.read          memory.write
pedagogy.node.entered pedagogy.decision    pedagogy.node.exited
```

事件外壳（envelope）**8 个公共字段，一个都不能少**：
`event_id` · `session_id` · `trace_id` · `timestamp` · `type` · `payload` · `source` · `sequence`

另外还有一条**不是 Runtime 事件**的推送通道 `pet:walk`（主进程漫游 / 拖动时发出，语义是「窗口正在移动」），**后端不要试图生产它**。

### 4.5 调试小抄

- **改 `renderer/` 下的代码**：热更新，直接生效。
- **改 `main/` / `preload/` 下的代码**：**必须重启**（主进程不自动重载）。
- **`npm run start` 不会重新编译** —— 它直接跑 `out/` 里的旧产物。改了源码没 `build`，预览到的还是旧的
  （`out/` 文件名带内容哈希，源码变了哈希才变）。「我改了怎么没生效」先怀疑这一条。
- **单实例锁**：反复 `npm run dev` / 双击启动会留下多个实例，默认位置几乎重合，看起来像"叠影""改了没生效""拖动就变大"。
  退出不干净时先确认没有残留进程。
- **退出不了**：`Ctrl+Alt+Shift+X` 强制退出；`Ctrl+Alt+Shift+D` 归位。
