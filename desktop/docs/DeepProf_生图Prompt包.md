## 〇、怎么用这份文档

**我（Claude）生不了图** —— 没有即梦 / 通义万相的调用能力，所以这份文档是给你**直接复制粘贴**用的清单。

用法：
1. 打开即梦（或通义万相）
2. **先传参考图**：`桌面\原创桌宠形象.png`（这是我们的基准形象）
3. 复制下面每一格的「中文 Prompt」，逐张生成
4. 每张生成后按文件名存好，丢进 `desktop\tools\素材流水线\动作帧\原始\<动作名>\`
5. 全部出完 → 跑 `做动作帧.bat` → 我负责归一化 + 出叠加预览图给你验收

**⚠️ 生成时务必：**
- 每张都**传同一张参考图**，保持角色一致
- 能固定随机种子的就固定（同一批尽量同种子）
- 导出**透明背景 PNG**；如果即梦不支持直接透明，就导出纯白背景，我们的脚本能抠（但**别用带渐变/花纹的背景**）
- **注意右下角水印**：即梦会打「即梦AI」水印，导出时能关就关；关不掉也没关系，抠图脚本会把连通到边缘的浅色一起吃掉

## 三、动作帧

### 3.1 ✅ 已拍板：走路帧用【侧视】（2026-09-19 张钧翔确认）

#### 为什么不能用正面（决策依据，留档）

设定文档 §2.1 的基准是**正面全身站姿**，但走路帧如果也用正面，会撞上物理限制：

```
正面视角                          侧视视角
      O                                O
     /|\  ← 身体不转                ／|\→  ← 朝右
     / \                              / \
    ↙   ↘                            →    ←
  腿往【屏幕里外】摆                 腿【前后剪开】
  横移时看不出在迈步                 横移时一眼是"在走"
```

桌宠走路 = **主进程移动窗口**，角色本身在原地做动作。
正视图中人走路时腿是往屏幕里外摆的，投影到平面上只剩一点点伸缩，
横移时就变成"**贴纸在滑**" —— 正是北极星里要避免的。
**「左右腿交替」在正面视角下物理上做不到被看见。**

#### 要出的 4 帧

> 全部**侧视、朝向画面右侧**。朝左不用另出图 —— 播放器有水平翻转，同一套帧翻过来就是朝左。

| 文件名 | 帧率 | 中间那行（配通用前缀 + 后缀） |
| --- | --- | --- |
| `walk_0.png` | 8 | 侧视图，朝向画面右侧，左腿向前迈出，右腿在后，双臂前后摆动，身体微微前倾 |
| `walk_1.png` | 8 | 侧视图，朝向画面右侧，双脚并拢，身体直立，双臂自然下垂（过渡帧） |
| `walk_2.png` | 8 | 侧视图，朝向画面右侧，右腿向前迈出，左腿在后，双臂前后摆动，身体微微前倾 |
| `walk_3.png` | 8 | 侧视图，朝向画面右侧，双脚并拢，身体直立，双臂自然下垂（过渡帧） |

#### 接受的代价（知情选择，不是没想到）

**切换走/停时视角会跳** —— 站着时是正面看着你，一走就"唰"地转成侧面。
这**不是转身动画**，是两张不同视角的图直接切换。

缓解：走路开始时本来就有身体起伏和上下的摆动，切换瞬间的注意力会被分散一部分。
而"看不出在走"是**持续存在**的问题，两害相权取轻。

#### 兜底

**出不了 4 帧就出 2 帧**（左右脚各一帧，6fps）——比 0 帧强得多，但比 4 帧明显糙。
**禁止 0 帧**（张钧翔指定的红线）。

#### ⭐ 一次出四格更省事（推荐）

把上面 4 帧的描述合成一段，让即梦**一次生成一张四格图**：

```
（通用前缀）
四格连续动作分解图，从左到右依次为走路循环的四个关键帧，角色始终朝向画面右侧：
第1格：左腿向前迈出，右腿在后，双臂前后摆动，身体微微前倾
第2格：双脚并拢，身体直立，双臂自然下垂（过渡帧）
第3格：右腿向前迈出，左腿在后，双臂前后摆动，身体微微前倾
第4格：双脚并拢，身体直立，双臂自然下垂（过渡帧）
四个角色等距排列、互不遮挡、比例一致，四周留足空白
（通用后缀）
```

**为什么推荐四格**：同一张画布内生成的四个姿势，**比例和步态连续性是天然对齐的**。
逐张生成时 AI 每次都会把角色画得大小不一、位置不一，归一化脚本只能对齐，
**修不了"这张画大了 20%"**。

切好的四格图跑 `裁四格.py` 自动切开。

## 四、技术要求（出图时就按这个来，能省掉后面返工）

| 项 | 要求 | 不遵守的后果 |
| --- | --- | --- |
| 背景 | **纯白**或透明 PNG | 抠图抠不干净，边缘挂灰 |
| 尺寸 | 表情 ≥1024px，动作帧 ≥512px | 放大后糊 |
| **画布** | ⚠️ **同一批帧必须同画布尺寸、同坐标** | **播放时角色会跳** |
| **脚底** | ⚠️ **同一批帧脚底必须落在同一条水平线上** | 同上 |
| 视角 | **同一批内**必须统一（别一张正面一张侧面） | 看着像换了个角色 |
| ↑ 注意 | 这是说**批次内部**要统一。**表情立绘那批是正面、走路那批是侧视** —— 这是已拍板的，不算违规 | — |
| 光照 | 统一（光从左上来） | 一致性差 |

> **出图时做不到完全对齐没关系** —— 归一化脚本会处理：裁透明边 → 统一缩放 → 头部中心对齐 → 脚底对齐。
> 但**同一批帧的角色大小别差太多**（脚本只能对齐，修不了"这张画大了 20%"）。
